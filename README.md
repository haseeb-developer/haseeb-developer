## Engineering Principles

- **Clarity first** — code should be easy to read before it's easy to write.
- **Function over flash** — every feature should earn its place in the interface.
- **Small, deliberate iterations** — build, test, refine.
- **Understand before abstracting** — no premature complexity.
- **Ship, then improve** — momentum matters more than perfection on day one.
